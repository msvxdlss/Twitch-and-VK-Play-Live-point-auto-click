# CHROMEWEBSTORE.md — Twitch and VK point clicker, v3.0

## Single purpose
Автоклик бонусов (channel points) на Twitch и VK Video Live.
Расширение делает ровно одну вещь: нажимает кнопку «забрать бонус»,
когда она появляется под чатом. Больше ничего.

## Manifest overview
- `manifest_version`: 3
- `name`: Twitch and VK point clicker
- `description`: Twitch and VK Video Live point clicker
- `permissions`: отсутствуют
- `host_permissions`: отсутствуют
- Background / service worker: нет
- Popup / options page: нет (content-scripts only)
- Remote code / внешние запросы: нет, весь код локален

## Content scripts и обоснование хостов
| Файл   | Match pattern                | Зачем нужен хост |
|--------|------------------------------|------------------|
| `tw.js` | `*://*.twitch.tv/*`         | Страницы стримов Twitch — отслеживает и кликает на сундук бонуса баллов канала |
| `vk.js` | `*://*.live.vkvideo.ru/*`  | Страницы стримов VK Video Live — отслеживает и кликает на сундук бонуса баллов канала |

Скрипты активны только на страницах этих двух доменов,
на остальных сайтах код не выполняется.

## Обоснование permissions
- Никаких API-разрешений (`storage`, `tabs`, `scripting` и т.д.) не используется,
  поэтому раздел permissions в манифесте пуст. Content scripts, объявленные
  в манифесте, отдельных разрешений не требуют.

## Privacy / сбор данных
- Данные пользователей не собираются, не хранятся и не передаются.
- Нет аналитики, нет сторонних библиотек, нет сетевых запросов.
- Для Data disclosure в панели разработчика: «не собирает данные».

## Как проверить
1. Открыть любой живой стрим на twitch.tv — дождаться сундука баллов
   (появляется раз в ~10–15 минут) — расширение кликнет его автоматически.
2. То же на live.vkvideo.ru — кнопка бонуса под чатом.
3. DevTools → Performance: в простое расширение не создает нагрузки
   (наблюдатель реагирует только на появление блока бонуса, чат игнорируется).
