Простое расширение которое дожидается изменения элемента под чатом, одним из таких изменение — появление иконки с бонусом, соотвественно кликается на нее сразу.

Очень ресурсоэфективное расширение, по сравнению с другими которые каждые 1-2 секунды проверяют весь документ на наличие нужной иконки. 


Как установить

Гугл расширения:

Руками с гитхаба:
1. Скачайте последний [релиз](https://github.com/msvxdlss/Twitch-and-VK-Video-Live-point-auto-click/releases), достаньте с него папку, и сохраните её где то далеко на диске, если её переместить Хром потом не будет её видеть.

2. Включите режим разработчика в расширениях.

3. Нажмите "Загрузить распакованое расширение".

4. Выберите ПАПКУ с файлами.
